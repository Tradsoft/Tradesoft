# Tradesoft
A robust backtesting tool for evaluating trading strategies on financial assets

## Project Overview

This project implements a comprehensive backtesting system that allows traders and analysts to evaluate the potential performance of trading strategies applied to historical financial asset data.

Developed by Master 2 IT for Finance students, this tool combines academic rigor with practical applicability for algorithmic trading.

## Features 
- Backtesting 
- Analyse de performance
- Interface Utilisateur
